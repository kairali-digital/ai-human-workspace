# TOOLBOX TEMPLATE

An installed or visible tool is not automatically allowed. A fresh worker may read
files already inside the worker for the declared task. Permission to create or edit the
bounded reversible local artifact the user explicitly requested becomes active only
after deterministic `task-start` returns the current task ID. Those
permissions exclude controlled state, `.ai-human/`, credentials, accounts, external
effects, deletion, unrecoverable overwrite, security changes and expanded scope. Add a
local `TOOLBOX.md` row only after the owner approves every other role, target and action.

| Surface | Use | Allowed by default | Approval required | Prohibited |
|---|---|---|---|---|
| Dedicated connector | Structured work in one approved service | Read records needed by the live task | Write, send, share, delete, permissions or new scope | Personal accounts; credential extraction |
| Existing work browser | Signed-in company sites | Read allowlisted low-risk pages | Form submission, upload/download, new site or broad history/local-file access | Personal, banking or password-manager profiles |
| Separate test browser | Public research and local testing | Public pages and approved local development | Login, upload or external write | Pretending it shares another browser's session |
| Computer control | Visible desktop interaction | Harmless test in an approved app | Security settings, new access or consequential data entry | Banking, passwords or warning bypass |
