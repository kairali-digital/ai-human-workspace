# Three-worker go-live

The employee-facing source of truth is
[`packages/kairali/homework/THREE-WORKER-GO-LIVE-CHECKLIST.md`](../packages/kairali/homework/THREE-WORKER-GO-LIVE-CHECKLIST.md).

Use it after the beginner setup path. It distinguishes a worker that is available in
the public kit from one that is activated and proven in an employee's separate local
project.

For the company rollout, Personal Work Memory + Daily Email EA and Full Drive Index are required.
Saturday LinkedIn Message Assistant is optional. `TEST 25` proves Drive setup only; it
does not complete the full-index homework. Every processing batch remains capped at 25
with a durable checkpoint before continuation. Drive completion additionally requires
the JSONL master and one generated Sheet-or-CSV human register to reopen under one
generation with reconciled counts, plus a verified-or-declined weekly schedule.
