# AI-Human Workspace v2.0.1

v2.0.1 makes ordinary work proportionate without weakening real safety. It corrects
the achievement-path defects found by the post-release v2.0.0 battle test.

## What changes

- Read-only questions return an answer without creating task state.
- A clear request for a reversible local result gets a generated task ID, standing
  worker-local permissions and deterministic start/close handling.
- Task close owns the exact cursor, register, today, ledger and evidence format, checks
  the declared local artifact, validates the final worker and never reports success on
  a failed close.
- Live-task parsing no longer mistakes a backticked filename for the task ID.
- Explanatory `PASS` text is normalized, while the explanation belongs in the
  verification field.
- Routine task wording no longer creates one-off tool-policy, fact or decision rows.
- A mixed request reads its company-specific gate, withholds only the gated part and
  keeps the safe local artifact on the proportional path without a redundant manual
  writer lease.
- A created artifact never repeats exact unsupported wording merely to explain a hold;
  it uses a complete paraphrased gate note or omits the reference.
- Literally false undo wording such as “no other files changed” cannot close a task.

## What does not change

- Gate 0 remains bound to the confirmed exact company/entity/unit/jurisdiction profile.
- Sending, publishing, buying, deleting, account access and security changes still
  require their declared approval.
- One intact uploaded file or assignment intake is never truncated because it contains
  more than 25 entries. Separately executed tasks or remote writes remain capped at 25
  per checkpoint.
- Kairali users and external users still download separate editions.

## Install or update

- **Existing v2.0.0 worker:** use the normal read-only update check and apply v2.0.1 at
  a safe checkpoint. User-owned work and state remain preserved.
- **Existing pre-v2 worker:** first complete the existing guided exact-scope Gate 0
  migration. This patch does not turn that migration into an automatic update.
- **New setup:** choose exactly one edition on the stable portal. Kairali staff use the
  Kairali Employee Edition; everyone else uses the company-neutral Reusable Edition.

Automatic update eligibility remains off. A public announcement or download is not
proof that an individual worker was updated; the worker's own validator is the proof.
