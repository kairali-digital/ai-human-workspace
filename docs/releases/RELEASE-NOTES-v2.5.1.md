# Windows 2.5.1

Earlier configured Windows workers first follow the signed 2.4.0 update guide. Mac users continue using their Mac release.

Windows workers can move from the published 2.4.0 edition using the updater inside the verified 2.5.1 ZIP. Open the approved release notice for the matching edition. Setup Helper verifies the signed commit, the ZIP, the worker repository and the manifest checksum before applying the update at a safe checkpoint. It records the backup and validates employee state afterward.

This version fixes registration of Windows tasks with Unicode paths and verifies removal against Task Scheduler. The reusable edition accepts local sources only. The first upgrade requires the verified edition bootstrap. Installing it does not enroll an employee in a scheduled update.
