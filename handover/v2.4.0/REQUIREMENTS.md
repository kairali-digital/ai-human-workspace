# Deduplicated requirements

## Must ship

1. One worker can choose `MONTHLY` or `QUARTERLY`, exact time and time zone.
2. Scheduled truth binds visible cadence, exact generated prompt hash and a bounded
   offset-aware next run. Configuration drift invalidates old proof.
3. The scheduled prompt actively gathers only owner-approved official, Reddit and
   YouTube findings and imports concise receipts in batches of no more than 25.
4. Raw pages, credentials and personal data are not stored. Source instructions are
   ignored. Reddit/YouTube need a dated source; official undated freshness is unknown.
5. Recommendations are derived from governed evidence, never supplied by an untrusted
   model file. Repeated-work signatures are stable and prior human decisions suppress
   identical future suggestions.
6. The user gets a readable brief with sources, links, priority-ranked opportunity,
   visible decision history and honest unknown value until owner-supplied observations
   measure a time difference. No money value is inferred.
7. `PROPOSE` creates only an inactive capability proposal. Dated `LATER` and `REJECT`
   persist across changing evidence IDs.
8. Automatic update checks preserve user state, serialize worker operations, defer live
   work, recover interrupted transactions, require same-batch fleet pilot proof and verify the
   canonical GitHub release owner, commit and signature.
9. Managed paths compare in a filesystem-portable form. Atomic writes do not use
   predictable fixed temporary names or follow a target symlink.
10. The v2.4 authority registry is exactly empty. Email/LinkedIn effects, silent skill
    activation and generic managed skill installation stop before effect state,
    provider contact, download, staging or runtime change.
11. Existing configured v2.0.0 through v2.3.0 workers retain their state. A pre-v2.4
    downgrade has a hash-inventoried recoverable private-state export/restore path.
12. Suspend and uninstall cannot report automation off while a known external schedule
    can still execute or be resumed.
13. Beginner, release, archive, portal and code-vetting gates must pass before publish.

## Deliberately not claimed

- No v2.4 managed mechanism sends email, replies, unsubscribes, changes filters or
  performs LinkedIn activity.
- No v2.4 managed mechanism installs or activates a skill.
- The workspace cannot contain arbitrary same-operating-system-user tools; host and
  connector isolation are separate boundaries.
- Time or money saved is not invented. It remains unknown until a client supplies a
  baseline and later observed result.
