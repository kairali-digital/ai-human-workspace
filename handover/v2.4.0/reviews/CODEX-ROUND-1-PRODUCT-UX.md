# Codex round 1 — product and client UX

Reviewer: independent product/UX critique agent
Initial verdict: **HOLD — 4.0/10**

The first review found one P0 and eleven major product failures:

- uninstall could report success with an external improvement schedule still alive;
- the generated scheduled prompt contradicted the unavailable skill boundary and did
  not describe an end-to-end run;
- no beginner activation journey existed and public instructions still named v2.3;
- research freshness, questions and approved domains were not actually enforced;
- evidence claims were discarded into generic recommendations;
- workflow identity and prior-decision suppression changed with growing evidence;
- “best opportunity” was selected by hash instead of product value;
- decision history and a useful dated `LATER` state were absent from the brief;
- no baseline/observed time-measurement loop existed;
- no governed pre-v2.4 private-state exit existed;
- automatic updates lacked a sufficiently honest activation and recovery story.

Required before re-review: close the schedule lifecycle gap; make the exact prompt
internally consistent and operational; add a natural-language activation journey;
scope and validate current research; preserve subject identity and decisions; rank
recommendations; add time measurement; add downgrade export/restore; regenerate the
public editions; and test the combined flows.

This document records the original review. Resolution claims belong in round 2 and
must be verified against code and tests, not accepted from this summary.
