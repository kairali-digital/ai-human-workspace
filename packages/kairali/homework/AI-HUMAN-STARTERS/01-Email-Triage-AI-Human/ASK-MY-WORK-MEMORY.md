# Ask my work memory

Use this contract whenever the employee asks a later question about their work,
priorities, people, commitments, preferences, emails or conversations.

1. Read `PERSONAL-WORK-MEMORY.md`, `MEMORY-SOURCES.md` and
   `MEMORY-REVIEW-QUEUE.md` first.
2. Answer from confirmed memory when it is current enough. Name the memory ID and its
   last-confirmed date in plain language.
3. If memory is missing, stale, observed-only or contradicted, say so. Search only the
   exact approved source and scope needed for the current question. Search email in
   batches of no more than 25 results and checkpoint before continuing.
4. Distinguish `CONFIRMED`, `OBSERVED — VERIFY`, and `NOT FOUND`. Never present an
   inference as a fact.
5. For Gate 0 or highly sensitive material, show only that human review is required;
   do not quote, summarize into memory or advise.
6. Do not open attachments, inspect unapproved folders, or use LinkedIn directly.
7. End with the answer, the sources and freshness used, and one concise memory
   correction or confirmation question only when it would materially improve future
   help.
