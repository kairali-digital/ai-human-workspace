# Memory review queue

Candidate learning appears here before it becomes confirmed memory. Keep each batch at
25 items or fewer.

| Candidate ID | Proposed concise memory | Why it may save time | Source reference | Evidence count | Status | Employee ruling |
|---|---|---|---|---|---|---|

Allowed rulings: `CONFIRM`, `CORRECT`, `KEEP AS OBSERVED`, `EXCLUDE`, `FORGET`, or
`NOT MEMORY`. Silence is not approval.
