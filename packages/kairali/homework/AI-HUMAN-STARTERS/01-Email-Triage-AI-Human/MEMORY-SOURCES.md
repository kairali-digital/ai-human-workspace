# Memory sources

Only sources the employee approves may support personal work memory or later answers.
The worker keeps the source where it belongs and stores only a locator here.

| Source ID | Source type | Approved account, file or scope | Allowed use | Coverage and freshness | Status |
|---|---|---|---|---|---|
| EMAIL-COMPANY | Gmail | Approved company mailbox — NOT SET | Search approved work email for the active task; never open attachments | NOT SET | NOT VERIFIED |
| DRIVE-METADATA | Local Drive index | Exact `DRIVE-INDEX.jsonl` path — NOT SET | Read metadata only to find likely work files; disclose generation, coverage and freshness; content needs a new approved task | NOT SET | NOT VERIFIED |
| LINKEDIN-MANUAL | Employee-supplied local export | Exact `CONFIRMED-LINKEDIN-LEARNINGS.md` path — NOT SET | Read only confirmed tone, people and work context supplied manually by the employee | NOT SET | NOT VERIFIED |

Do not silently browse another worker folder. The employee approves the exact local
path before it becomes `ACTIVE`, and later use reports the source date and coverage.
