# Personal work memory

This is the employee-owned file of record for reusable work context. It stores concise,
source-backed context, not copies of the mailbox or private conversations.

## Controls

- Owner: Kairali employee using this copy
- Status: EMPTY — BUILD THE SUPERVISED BASELINE
- Last reviewed: NOT SET
- Excluded topics or people: NONE SET

The employee may say `SHOW MY MEMORY`, `CORRECT MEMORY <ID>`, `FORGET <ID>`,
`EXCLUDE <topic or person>` or `REFRESH MEMORY` at any time. A forgotten item is
removed from the active sections and recorded only as a content-free deletion receipt
in `DECISIONS.md`.

## Memory rules

- `CONFIRMED` means the employee explicitly confirmed the item.
- `OBSERVED — VERIFY` means repeated approved evidence supports an inference; answers
  must disclose that it is not confirmed.
- Every active item needs a source reference, date and review point. Stale or
  contradicted items move to `MEMORY-REVIEW-QUEUE.md`.
- Never store passwords, codes, credentials, banking data, personal HR details,
  medical information, dosage, certification decisions, legal advice or spend
  authority here.
- Never treat silence, a single unconfirmed message or an AI-generated draft as a
  durable preference.
