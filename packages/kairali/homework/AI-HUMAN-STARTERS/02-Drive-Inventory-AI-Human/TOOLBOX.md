# TOOLBOX

An available tool is not automatically an allowed tool. Add a row before relying on it.

| Tool | Purpose | Allowed actions | Approval needed | Required proof |
|---|---|---|---|---|
| Google Drive connector in Apps | Read connector-visible metadata | Search or list metadata from the approved company Drive in batches of at most 25; cover owned/created, shared-with, shared-by and shared-drive scopes when exposed; never fetch file contents | Employee completes the provider login or account-choice screen; no password or one-time code is shared with the AI | Batch count, durable cursor, scope coverage, unique-item count and Drive-unchanged statement |
| Local project files | Preserve and verify the master index and proof | Create or update `DRIVE-INDEX.jsonl`, `DRIVE-REGISTER.csv` only when it is the selected human register, `DRIVE-INDEX.md`, `DRIVE-INDEX-RECEIPT.json`, `DRIVE-INDEX-CURSOR.json` and state files; reopen the selected outputs; run `validate_drive_register.py` | No extra approval inside this folder | Both register readbacks, generation/count agreement, relationship and refresh counts, validator, checkpoint, ledger and evidence rows |
| Google Sheets connector in Apps — optional human register | Maintain the one human-readable register from the local JSONL file of record | Create or update only the exact approved Sheet/range; read it back for generation and row-count proof | Connector and write permission must already be available; employee approves `GOOGLE SHEET` and the exact target before the write | Sheet ID/link without secrets, range, generation ID, data-row count and agreement with JSONL/summary/cursor |
| Codex automation | Offer an optional weekly metadata refresh after full proof | Create one job against this exact project using `WEEKLY-DRIVE-REFRESH-PROMPT.md`; view, pause, edit or remove its card; never duplicate or silently enable | Employee confirms day, exact local time, time zone and activation | Card, schedule, project, prompt, ACTIVE status and matching `AUTOMATIONS.md` row |
