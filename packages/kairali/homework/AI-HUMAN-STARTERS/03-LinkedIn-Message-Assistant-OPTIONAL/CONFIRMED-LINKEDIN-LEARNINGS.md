# Confirmed LinkedIn learnings

This employee-owned export contains only concise learning the employee explicitly
approved from manually supplied LinkedIn conversations and confirmed outcomes. It is
not a copy of the LinkedIn inbox.

| Learning ID | Person or pattern | Concise confirmed work context or tone rule | Source queue item | Confirmed UTC | Status |
|---|---|---|---|---|---|

Do not store full conversations, passwords, codes, attachments, sensitive traits,
private relationships, Gate 0 content or unconfirmed inference. The employee may
say `CORRECT LINKEDIN LEARNING <ID>` or `FORGET LINKEDIN LEARNING <ID>` for any row.
Another worker may read this file only after the employee
approves its exact local path as a source.
