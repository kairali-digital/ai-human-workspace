# Right-level Computer and Chrome handoff

This project may use ChatGPT Computer Use for the local worker and `@Chrome` for an
approved non-LinkedIn page. That permission does **not** authorize access to LinkedIn.

## Step 1 - prove local Computer control

1. Close every LinkedIn tab and the LinkedIn app.
2. In this local project, start a message with `@Computer` and send:

   ```text
   Check this local LinkedIn Message Assistant folder. Do not open or view LinkedIn.
   Show me the first safe setup action and stop before any external website.
   ```

3. ChatGPT may show its real Computer Use permission prompt. Read the prompt and
   approve only this task and the visible app or folder. Keep **Ask for approval**.
   Never choose **Full access**, **Always allow**, your whole computer, or another
   employee's screen.
4. On Mac, approve Screen Recording or Accessibility for ChatGPT only if the operating
   system asks for that exact permission. On Windows, keep the target app visible and
   approve one request at a time.

**DONE WHEN:** Codex can name `AGENTS.md` and `LINKEDIN-CONTROL-HANDOFF.md` from this
local project, and it confirms that LinkedIn is outside the granted task.

## Step 2 - use Chrome only outside LinkedIn

Use `@Chrome` only for an approved non-LinkedIn page, such as the official Computer Use
guide. The employee sees the actual browser permission request and approves only that
page and task. Never use `@Chrome` while a LinkedIn page is open.

**DONE WHEN:** Codex can open an approved public setup page, then closes or leaves that
page and stops browser control before LinkedIn is opened.

## Step 3 - employee takes over for LinkedIn

Before the employee opens LinkedIn, Codex must stop Computer Use and `@Chrome`, make no
more computer or browser tool calls, and show exactly:

```text
YOUR TURN ON LINKEDIN
Computer and browser control are stopped.
Open LinkedIn yourself, check Focused and Other, and copy no more than 25 conversations.
Do not share passwords, codes, attachments, suspicious links or sensitive personal data.
Close LinkedIn, return to this local project, paste the batch, and say BATCH READY.
```

While LinkedIn is visible, the AI must not inspect a screenshot or page structure, move
the pointer, click, type, read, copy, paste, search, open a link or attachment, or send.
The employee alone performs those actions.

**DONE WHEN:** LinkedIn is closed, the employee is back in this local project, the
employee-supplied batch contains no more than 25 conversations, and the employee says
`BATCH READY`.

## Step 4 - resume only in the local project

After `BATCH READY`, Codex may resume Computer Use only for this local folder if an
access prompt is shown and approved. It processes the pasted text, prepares drafts and
stops again before the employee returns to LinkedIn to send anything.

**DONE WHEN:** The queue is saved locally, every LinkedIn send is performed and
confirmed by the employee, and the evidence log records that no AI LinkedIn action
occurred.

The portal can link to these instructions, but a website button cannot grant operating
system or browser control. Only ChatGPT's real, task-time permission prompt can do that.
